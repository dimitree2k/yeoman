# Third-party assets

## Meme templates (`templates/`)

The template images and `config.yml` files come from
[jacebrowning/memegen](https://github.com/jacebrowning/memegen) (commit
`3b1cc2dc88d28dceba6c4299a95ca9f73d6134b8`), MIT License, Copyright 2020 Jace Browning.
See `templates/LICENSE-memegen.txt`.

Changes: only the `default` image of each template is kept, converted to JPEG and scaled
down to at most 800 px wide. The configs are unchanged. memegen's fonts are not included.
